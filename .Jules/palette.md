## 2025-03-08 - Added ARIA Labels to Social Links\n**Learning:** Icon-only anchor tags, even when wrapping SVG elements with standard icons, need explicit `aria-label` attributes to ensure screen readers can announce the link destination properly. Missing labels create an opaque experience for assistive technologies.\n**Action:** Always add `aria-label` attributes to any `<a>` or `<button>` tag that only contains icons and no visible text.
